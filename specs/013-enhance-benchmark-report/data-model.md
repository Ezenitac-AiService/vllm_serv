# Data Model: Enhanced Benchmark Report & Qualitative Answer Comparison

**Feature Directory**: `specs/013-enhance-benchmark-report`  
**Created Date**: 2026-07-29  

---

## Data Entities

### 1. QualitativeSampleComparison
Represents a single side-by-side prompt-answer comparison between Golden Ground Truth and a model's generated output.

- `prompt_id` (`str`): Unique ID of the prompt (e.g. `ATEAM-STOCK-01`).
- `prompt_text` (`str`): Input user prompt text.
- `golden_ground_truth` (`str`): Golden reference ground truth answer text.
- `model_response` (`str`): Actual raw output text generated by the model.
- `rouge_l_f1` (`float`): ROUGE-L F1 similarity score (0.0 to 1.0).
- `exact_match` (`bool`): Whether key domain slots matched 100% exactly.
- `json_schema_valid` (`bool`): Whether structured JSON parsing succeeded.
- `error_tags` (`List[str]`): List of error classification tags (e.g., `["[Entity Hallucination]", "[Pronoun Unresolved]"]`).

### 2. ContextScalingMetric
Represents context window scaling performance across different `n_ctx` sizes.

- `n_ctx` (`int`): Context window size tested (`4096`, `8192`, `16384`, `32768`).
- `peak_vram_mb` (`float`): Peak GPU VRAM allocated during inference.
- `ttft_ms` (`float`): Time To First Token in milliseconds.
- `tpot_tok_per_sec` (`float`): Tokens Per Output Token per second.
- `is_oom` (`bool`): `True` if CUDA Out-Of-Memory error occurred.

### 3. ComprehensiveQualityReportMetric (Extended)
Aggregates performance, quality scores, qualitative samples, and context scaling for a model.

- `model_id` (`str`): Model identifier (e.g. `gemma4-e2b`, `qwen3.5-4b`).
- `quant_type` (`str`): Quantization algorithm (`q4_k_m`, `qat_q4_0`).
- `load_time_sec` (`float`): Model loading time in seconds.
- `ttft_ms` (`float`): TTFT in milliseconds.
- `tpot_tok_per_sec` (`float`): TPOT generation speed in tok/s.
- `peak_vram_mb` (`float`): Peak VRAM allocated in MB.
- `avg_quality_score` (`float`): Overall quality score (1.0 to 5.0).
- `quality_per_speed_index` (`float`): Quality per speed index.
- `quality_per_vram_index` (`float`): Quality per VRAM index.
- `is_oom` (`bool`): OOM status flag.
- `error_message` (`Optional[str]`): Failure reason if status is failed.
- `qualitative_samples` (`List[QualitativeSampleComparison]`): Sample diff list.
- `context_scaling_metrics` (`List[ContextScalingMetric]`): Context window scaling list.
