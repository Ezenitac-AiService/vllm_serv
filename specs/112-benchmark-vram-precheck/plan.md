# Implementation Plan: 벤치마크 품질 평가 스크립트 VRAM 용량 사전 검증 및 자동 스킵 (Benchmark VRAM Pre-check & Auto-Skip)

**Branch**: `112-benchmark-vram-precheck` | **Date**: 2026-08-08 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/112-benchmark-vram-precheck/spec.md`

## Summary

`benchmark_quality.py` 및 `model_downloader.py` 구동 시 물리 GPU VRAM 용량을 초과하는 대형 모델(26B/27B 등 16GB+ GGUF)의 무의미한 가중치 다운로드 및 서빙 프로세스 개설 시도로 인한 대역폭/시간 낭비와 런타임 CUDA OOM 크래시를 사전 차단하기 위해, 다운로드 및 로컬 서빙 개설 직전에 `ProcessManager` VRAM 안전 공식 기반의 사전 검증 및 자동 스킵(Pre-check & Auto-Skip) 기능과 CLI 우회 옵션(`--ignore-vram-check`), 전수 모델 VRAM 수용 적합성 요약표를 전면 구현하고 단위 테스트 수트에 검증 케이스를 수록합니다.

## Technical Context

**Language/Version**: Python 3.12 (uv package manager) / POSIX Bash

**Primary Dependencies**: `scripts/model_downloader.py`, `scripts/benchmark_quality.py`, `src/core/process_manager.py`, `src/core/gpu_detector.py`, `src/core/config_manager.py`

**Storage**: Local models directory (`models/`), JSON catalogs (`config/model_catalog.json`)

**Testing**: `uv run pytest tests/unit/test_benchmark_context.py tests/unit/test_model_downloader.py`

**Target Platform**: Linux server (Xeon / i7 / GTX 1080 Ti / RTX 3060 / RTX 4090, CUDA 12.x)

**Project Type**: CLI Script / Benchmark Automation Utility

**Performance Goals**: 0초 다운로드 시간 낭비 (VRAM 초과 대형 모델 사전 즉시 스킵)

**Constraints**: `ProcessManager` VRAM 안전 공식(GGUF 가중치 용량 + KV Cache)과 100% 동일한 로직 공유, `--ignore-vram-check` CLI 우회 플래그 지원, FR-006 준수(로컬 가중치 존재 시에도 VRAM 초과 시 서빙 개설 사전 스킵)

**Scale/Scope**: `scripts/model_downloader.py`, `scripts/benchmark_quality.py`, `tests/unit/test_benchmark_context.py`, `tests/unit/test_model_downloader.py`
