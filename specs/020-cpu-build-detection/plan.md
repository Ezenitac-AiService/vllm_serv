# Implementation Plan: CPU 빌드 감지 및 다중 플랫폼 지원 (llama.cpp)

**Branch**: `020-cpu-build-detection` | **Date**: 2026-07-30 | **Spec**: [spec.md](file:///home/dev/storage/vllm_serv/specs/020-cpu-build-detection/spec.md)

**Input**: Feature specification from `/specs/020-cpu-build-detection/spec.md`

## Summary

i7 930(Nehalem, SSE4.2 전용)과 같은 레거시 CPU 환경 및 GTX 1070(Pascal, `sm_61`)과 같은 다양한 타겟 하드웨어 플랫폼에서 llama.cpp(`llama-server` 네이티브 CMake 빌드 및 `llama-cpp-python` pip 빌드) 컴파일 시, CPU 명령어 세트(AVX/AVX2/F16C/FMA) 및 GPU Compute Capability를 자동으로 감지하여 최적의 호환 컴파일 플래그(`-DGGML_AVX=OFF` 등)를 결정하는 하드웨어 감지 모듈 및 빌드 파이프라인 연동을 구축합니다.

## Technical Context

**Language/Version**: Python 3.11+, Bash shell  
**Primary Dependencies**: Pydantic v2, CMake 3.28+, llama-cpp-python, uv  
**Storage**: JSON file configuration (`config/platform_profiles.json`)  
**Testing**: pytest (`tests/unit/test_cpu_detector.py`, `tests/integration/test_build_pipeline.py`)  
**Target Platform**: Ubuntu Server 24.04 LTS (x86_64, i7 930 + GTX 1070) 및 기존 개발 시스템 (x86_64, Modern CPU + RTX 3060)  
**Project Type**: System integration & build automation pipeline  
**Performance Goals**: CPU 기능 감지 < 50ms, 빌드 플래그 생성 < 10ms, 기존 최신 CPU 성능 저하 없음  
**Constraints**: CPU-only 빌드 불허 (NVIDIA GPU 가속 필수 fail-fast), 크로스 컴파일 제외 (타겟 머신 직접 빌드)  
**Scale/Scope**: 2개 이상의 타겟 하드웨어 프로필 지원, 네이티브 CMake 및 pip 설치 경로 커버
