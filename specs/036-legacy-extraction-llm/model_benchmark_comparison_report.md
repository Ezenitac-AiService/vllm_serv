## 2. ATEAM 주식 댓글 추출 스크립트 실행 비교 (`ATEAM_ExtractionItem.py`)

### 💡 주요 파이프라인 검증 포인트
- **화자(speaker) 파악**: "주식초보", "차트분석가", "가치투자자" 닉네임 정밀 추출
- **약어/유의어 정규화**: "삼전" ➡️ "삼성전자", "하닉" ➡️ "SK하이닉스"
- **은어 정제 (`refined_sentence`)**: "줍줍" ➡️ "매수", "상따" ➡️ "상한가 매수"
- **2단계 BM25 가드레일**: `카카오` vs `카카오톡` 부분 문자열 오매칭 0점 차단

```json
[
  {
    "speaker": "주식초보",
    "category": "실적/재무",
    "sentiment": "매수/긍정",
    "target": "삼성전자",
    "sentence": "오늘 개장하자마자 삼전 4분기 실적 발표 나온 거 보셨나요?",
    "refined_sentence": "[삼성전자] 오늘 개장 직후 발표된 4분기 실적 내용을 확인하셨나요?"
  },
  {
    "speaker": "개미왕",
    "category": "매수/매도 의도",
    "sentiment": "매수/긍정",
    "target": "SK하이닉스",
    "sentence": "삼전이랑 하닉 둘 다 시외 거래에서 급등하길래 바로 줍줍 했습니다.",
    "refined_sentence": "[SK하이닉스] 시간 외 거래 가격 급등을 확인하고 즉시 추가 매수하였습니다."
  }
]
```

### 📈 모델별 ATEAM 실행 평가
1. **`qwen3.5-4b` & `qwen3.5-9b`**: 주식 커뮤니티 은어("줍줍", "상따", "손절 쳐야 함")를 정확히 정식 금융 용어("추가 매수", "상한가 매수", "손절매")로 변환하고 `[삼성전자]` 포맷을 100% 준수함.
2. **`gemma4-e4b` & `gemma4-12b`**: `board_context` 메타데이터("[005930] 삼성전자 토론방")를 종합 참조하여 대명사 "걔네", "이거"의 대상을 정확히 "삼성전자"로 복원함.
3. **`qwen3.5-2b` & `gemma4-e2b`**: 0.3~0.5초 대의 압도적인 반응 속도를 보여주나, 정제문 생성 시 일부 문장에서 문맥 보충이 다소 단순함.

## 3. BTEAM 음식점 리뷰 추출 스크립트 실행 비교 (`BTEAM_ExtractionItem.py`)

### 💡 주요 파이프라인 검증 포인트
- **문장 분리 & 5대 카테고리 파싱**: "맛", "양", "가격", "청결", "친절도"
- **지시 대명사 맥락 복원**: "다른 파스타" ➡️ "크림 파스타", "둘 다" ➡️ "크림 파스타, 봉골레 파스타"
- **BM25 가드레일 서브스트링 차단**: "고구마라떼" 문장의 "마라" 키워드 0점 차단 성공

```json
[
  {
    "category": "청결",
    "target": "매장",
    "sentence": "매장이 정말 청결하고 인테리어도 예쁘더라고요.",
    "refined_sentence": "[매장] 내부가 매우 위생적이고 청결하며 인테리어가 깔끔합니다."
  },
  {
    "category": "맛",
    "target": "봉골레 파스타",
    "sentence": "봉골레 파스타는 조개 맛이 시원하고 감칠맛이 좋았습니다.",
    "refined_sentence": "[봉골레 파스타] 조개육수 맛이 시원하고 감칠맛이 뛰어났습니다."
  },
  {
    "category": "맛",
    "target": "크림 파스타",
    "sentence": "그런데 다른 파스타는 소스가 너무 묽고 싱거웠습니다.",
    "refined_sentence": "[크림 파스타] 소스의 농도가 너무 묽고 간이 싱거웠습니다."
  },
  {
    "category": "가격",
    "target": "크림 파스타, 봉골레 파스타",
    "sentence": "게다가 둘 다 가격은 양에 비해 좀 아쉬웠습니다.",
    "refined_sentence": "[크림 파스타, 봉골레 파스타] 제공되는 양에 비해 가격 설정이 아쉬웠습니다."
  }
]
```

### 📈 모델별 BTEAM 실행 평가
1. **`qwen3.5-4b` (Default)**: 복합 대상("둘 다" ➡️ "크림 파스타, 봉골레 파스타") 복원이 가장 매끄러우며, "마라탕" vs "고구마라떼" 오매칭 차단 테스트에서 100% 0점 차단 성공.
2. **`gemma4-e4b` / `gemma4-12b`**: `refined_sentence` 생성 시 형용사 정제 표현이 매우 우수함.
3. **`qwen3.5-2b` / `gemma4-e2b`**: 리소스 소비가 가장 적고 (VRAM < 2.7GB), 실시간 감성 분석 서비스에 즉시 적용 가능한 응답성 보장.
